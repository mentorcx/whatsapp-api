# assets/

Diagramas, screenshots y otros recursos visuales referenciados desde la wiki.

## Reglas

- Preferir **Mermaid inline** en Markdown antes que imagen.
- Si se necesita imagen, formato SVG cuando sea posible.
- Nombre del archivo: `seccion-tema-version.ext` (ej: `02-webhooks-flow-v1.svg`).
- Cada asset referenciado desde al menos un `.md` de la wiki.
- Anonimizar capturas (sin datos personales ni tokens).
