# 11 · Glosario

Términos canónicos usados en toda la wiki.

## Formato

- Versión humana legible: este README + un archivo por término extenso.
- Versión machine-readable: [`glossary.json`](../glossary.json) en la raíz.

Cuando un término aparece en el JSON, **usar exactamente esa grafía** en toda la wiki para que un LLM pueda hacer matching directo.
