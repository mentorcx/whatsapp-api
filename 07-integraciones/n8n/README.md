# n8n

Orquestación de flujos de WhatsApp con n8n.

## Documentos planeados

- `setup.md` — Instalación, queue mode, credentials.
- `nodo-whatsapp-cloud.md` — Configuración del nodo oficial.
- `webhook-entrante.md` — Recibir mensajes, verificación de firma.
- `patrones.md` — Router por tipo de mensaje, deduplicación, sesiones.
- `contexto.md` — Almacenar contexto en Postgres / Redis / Airtable.
- `subflows.md` — Subflows reutilizables (enviar plantilla, media, etc.).
- `errores-comunes.md` — Webhooks duplicados, timeouts, rate limits.
