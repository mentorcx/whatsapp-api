# Evolution API

API REST no oficial basada en Baileys. Útil para prototipos e integraciones de bajo volumen.

## Documentos planeados

- `instalacion.md` — Self-host con Docker (alternativa a Railway).
- `instancias.md` — Una instancia por número, QR vs pairing code.
- `endpoints.md` — `/message/sendText`, `/message/sendMedia`, `/instance/connect`.
- `eventos.md` — Webhooks: MESSAGES_UPSERT, CONNECTION_UPDATE, etc.
- `v1-vs-v2.md` — Diferencias y breaking changes.
- `riesgos.md` — Ban, ToS, cuándo NO usarlo.
- `integraciones.md` — Chatwoot, Typebot, n8n.
