# examples/

Payloads JSON reales (anonimizados) y workflows exportables que respaldan la documentación.

## Convención de archivos

- `webhooks/` — Payloads entrantes de Cloud API, Evolution API, Respond.io, Kommo.
- `n8n/` — Workflows exportados (`.json`) listos para importar.
- `curl/` — Snippets `.sh` con `curl` reproducibles.
- `prompts/` — System prompts y user prompts de las recetas.

Cada archivo debe estar referenciado desde al menos un documento de la wiki.
